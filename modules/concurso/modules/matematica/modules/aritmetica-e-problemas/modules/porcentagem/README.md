## Fórmulas (relações) de porcentagens

> Quais são as fórmulas (relações) mais comuns para encontrar porcentagens?

Por exemplo:

- Qual a fórmula para descobrir/calcular a porcentagem que uma parte representa do todo?
- Qual a fórmula para descobrir/calcular uma parte correspondente a uma determinada porcentagem do todo?
- Qual a fórmula para descobrir/calcular o todo quando conhecemos uma parte e a porcentagem que ela representa?

<details>

<summary>RESPOSTA</summary>

<br/>

| O que queremos descobrir | Fórmula                                                                                   |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| **Porcentagem**          | $\text{Porcentagem}=\frac{\text{Parte}}{\text{Todo}}\times100$    |
| **Parte**                | $\text{Parte}=\frac{\text{Porcentagem}}{100}\times\text{Todo}$    |
| **Todo**                 | $\text{Todo}=\frac{\text{Parte}}{\frac{\text{Porcentagem}}{100}} \leftrightarrow \text{Todo}=\frac{\text{Parte}\times100}{\text{Porcentagem}} $  |

</details>
